# 🎨 SKILL: Frontend Master (Anthropic & Vercel Design System)

## 📌 Назначение
Этот навык регламентирует верстку и дизайн в десктопных и веб-приложениях (React, TypeScript, Tailwind CSS, Tauri v2). Он гарантирует качество уровня Linear / Raycast / Vercel.

---

## ⚡ 1. Золотые правила типографики и цветов
* **Контраст и читаемость:** Использовать многоуровневые оттенки цинка/нейтралей (`text-zinc-100` для заголовков, `text-zinc-400` для вторичного текста, `text-zinc-500` для меток и таймстампов).
* **Акцентные цвета:** Один доминантный акцент (`text-primary` / `bg-primary`) с прозрачными подложками (`bg-primary/10`, `border-primary/20`) вместо кричащих сплошных заливок.
* **Шрифты:** Использовать системные гротески (`Inter`, `-apple-system`, `system-ui`) и моноширинные шрифты (`JetBrains Mono`, `font-mono`) для хэшей, IP-адресов, цен и метрик.

---

## 📐 2. Структура компонентов (Vercel Composition Patterns)
* **Состояния элементов (4x2 матрица):** Каждый интерактивный элемент обязан иметь стили для:
  1. `default` (базовое состояние);
  2. `hover` (`hover:bg-zinc-800`, плавный `transition-colors`);
  3. `active` / `focus-visible` (`outline-none ring-2 ring-primary/40`);
  4. `disabled` (`disabled:opacity-50 cursor-not-allowed`).
* **Асинхронные индикаторы:** При операциях дольше 100 мс — всегда спиннер (`Loader2` из lucide-react с `animate-spin`) и деактивация кнопки для предотвращения двойных кликов.

---

## 📱 3. Адаптивность и чистая геометрия
* **Сетка Flex / Grid:** Избегать фиксированных ширин в пикселях (`w-[342px]`). Всегда использовать `flex-1`, `w-full max-w-xl`, `grid grid-cols-1 md:grid-cols-2`.
* **Скругления и тени:** Единый радиус (`rounded-xl` для карточек, `rounded-lg` для кнопок, `rounded-full` для бейджей). Тонкие границы `border border-border/80` вместо тяжёлых теней.

---

## 🛡️ 4. Анти-Slop UI Гейты (Anti-Slop Standard по ux-ui-agent-skills)
Категорически запрещены статистические галлюцинации моделей («AI Slop»):
1. **Запрет градиентного мусора:** Запрещены произвольные градиенты индиго-пурпур (`bg-gradient-to-r from-indigo-500 to-purple-600`) для шапок. Фон должен быть строгим и чистым (`bg-zinc-950` / `bg-zinc-900`).
2. **Токен по назначению (Token-by-Intent):** Деструктивные действия (`Удалить`, `Очистить`, `Сброс`) ВСЕГДА в тоне `destructive` / `red-500` (никаких синих кнопок удаления!). Первичные действия — в `primary`.
3. **Запрет эмодзи вместо иконок:** В интерфейсах запрещено вставлять Unicode эмодзи (🚀, 📊, ⚙️) вместо контролов. Использовать исключительно векторные SVG (`lucide-react`).
4. **Контраст WCAG 2.2 AA:** Минимальный контраст текста к фону — 4.5:1 для обычного текста, 3.0:1 для заголовков. Никакого светло-серого текста на белом фоне.
5. **Целевой размер (Target Size):** Интерактивные кнопки и элементы управления обязаны иметь кликабельную область не менее 32×32px (минимум 24×24px по WCAG 2.5.8).
6. **Разнообразие форм и смысловой фокус:** Главная метрика (Hero figure) ведет размер в 2.5–3x от базового текста; сопутствующие блоки не должны быть 4 одинаковыми серыми карточками — использовать разные формы (таблицы, списки активности, графики).
