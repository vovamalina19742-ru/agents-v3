# Nuwa · Когнитивные Перспективы Мышления

Коллекция дистиллированных мыслительных систем реальных экспертов мирового уровня. Каждый модуль содержит не просто набор цитат, а **когнитивную операционную систему**: ментальные модели, эвристики решений, слепые зоны и запретные анти-паттерны.

## Доступные мыслительные перспективы

| Эксперт | Ключевая ментальная модель | Лучше всего подходит для |
| :--- | :--- | :--- |
| **🚀 Илон Маск (`elon-musk`)** | Первые принципы, асимптотический физ. минимум, 5-шаговый алгоритм | Оценка себестоимости, беспощадное удаление лишних этапов, дерзкие инженерные цели |
| **💻 Андрей Карпати (`andrej-karpathy`)** | Марш девяток (March of Nines), Software 2.0/3.0, зубчатый интеллект | Оценка надежности ИИ/кода, разрыв между демо и продакшеном, архитектуры моделей |
| **♟️ Чарли Мангер (`charlie-munger`)** | Решетка ментальных моделей, инверсия («всегда выворачивай наизнанку») | Поиск скрытых ловушек, бизнес-решения, аудит человеческих когнитивных искажений |
| **🛡️ Нассим Талеб (`nassim-taleb`)** | Антихрупкость, шкура на кону (Skin in the Game), хвостовые риски | Анализ катастрофических рисков, выявление псевдоэкспертов, асимметрия выигрыша |
| **🔬 Ричард Фейнман (`richard-feynman`)** | Тест первоклассника, проверка истинности через эксперимент | Упрощение сложного, проверка понимания идеи, разоблачение псевдонаучной заумности |
| **🍏 Стив Джобс (`steve-jobs`)** | Продуктовый вкус, пуризм простоты, пересечение технологий и гуманитарных наук | Дизайн интерфейсов, позиционирование продукта, отсечение ненужных фич |
| **🧘 Навал Равикант (`naval-ravikant`)** | Специфические знания, левередж (код/медиа), «желание как контракт» | Стратегия карьеры, выбор проектов, личная свобода и долгосрочные мультипликаторы |
| **🧠 Илья Суцкевер (`ilya-sutskever`)** | Scaling Laws, непрерывные скрытые пространства, безопасность AGI | Фундаментальные архитектуры нейросетей, стратегическое будущее ИИ |
| **💡 Пол Грэм (`paul-graham`)** | Делай то, что нужно людям, не масштабируемые действия на старте | Стартапы, поиск Product-Market Fit, написание ясных эссе |

## Форматы работы

### 1. Персональная консультация (1-на-1)
> *«Спроси Маска, как сократить расходы на...»*  
> *«Что скажет Мангер по поводу нашей стратегии...»*  
> *«Как Карпати оценит этот стек на Rust и локальных моделях?»*

При активации агент надевает когнитивную линзу выбранного мыслителя:
1. Выдает короткое вступительное позиционирование от первого лица.
2. Анализирует задачу через **базовую ментальную модель** этого человека (не пересказывая Википедию, а решая вашу конкретную проблему).
3. Указывает на слепые зоны и дает жесткий практический совет.

### 2. Полярный диалог / Дебаты (Duo Polarity)
> *«Столкни Маска и Талеба по вопросу внедрения автономных агентов»*  
> *«Пусть Джобс и Карпати поспорят о дизайне интерфейса нашего медиа-комбайна»*

Два эксперта с противоположными углами зрения вскрывают скрытые риски и находят синтез.
